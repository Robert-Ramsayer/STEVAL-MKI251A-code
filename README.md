Welcome

I set this up for a Raspberry Pi Pico W because it's what I had around: very cheap. 

You're going to need the wireing diagram for the STEVAL-MKI251A:
https://www.st.com/resource/en/schematic_pack/steval-mki251a-schematic.pdf

Also the diagram for the Rasp. Pi. Page 5 in the book: 
https://pip-assets.raspberrypi.com/categories/686-raspberry-pi-pico-w/documents/RP-008312-DS-1-pico-w-datasheet.pdf?disposition=inline

As for which wires: 
VDD    → 3V3

VDDIO  → 3V3

GND    → GND

SDA    → GP4

SCL    → GP5

CS     → 3V3

SDO    → GND
